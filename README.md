# Emily Mamabolo – Professional Portfolio

Modern, responsive personal portfolio website for **Moremadi Emily Mamabolo**, Software Developer and final-year BSc Information Technology (Software Engineering) student.

## Features

- Dark modern theme with violet / cyan accents
- Responsive design (mobile-first)
- Professional circular profile photo
- Sections: Home, About, Skills, Experience, Projects, Education & Certifications, Contact
- Live project showcase including **Phuthabogale Fleet Website**
- Smooth scrolling navigation + mobile menu
- Contact form (opens mailto with pre-filled details)

## How to view locally

1. Open the `portfolio` folder
2. Double-click `index.html` or open it in Chrome / Edge / Firefox

## How to deploy to GitHub Pages

1. Create a new repository (or update `portfolio-website`)
2. Upload all files inside the `portfolio` folder (index.html, css/, js/, assets/)
3. Enable GitHub Pages on the main branch
4. Your site will be live at `https://emilymoremadi.github.io/<repo-name>/`

Alternatively replace the contents of your existing `portfolio-website` repository with these files.
